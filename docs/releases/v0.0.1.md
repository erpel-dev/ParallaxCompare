First preview of ParallaxCompare: a fast side-by-side compare tool for folders, archives and Git revisions on Windows and Linux.

## Downloads

All files are standalone: no installer, nothing to set up.

| File | What it is |
|---|---|
| `ParallaxCompare-v0.0.1-windows-x64.exe` | Desktop app for Windows 10/11 (x64). Needs the Microsoft Edge WebView2 runtime, which Windows 11 and current Windows 10 already include. |
| `parallax-v0.0.1-windows-x64.exe` | Command-line tool for Windows |
| `ParallaxCompare-v0.0.1-linux-x86_64.AppImage` | Desktop app for Linux (x86-64). `chmod +x` and run. Without FUSE, run it with `--appimage-extract-and-run`. |
| `parallax-v0.0.1-linux-x86_64` | Command-line tool for Linux, statically linked, runs on any x86-64 distribution |
| `SHA256SUMS.txt` | Checksums of all files |

The executables are not code-signed yet. Windows SmartScreen will warn on first start ("More info" → "Run anyway").

## What it does

- Compare any two **sources**: local folders, archives (zip, 7z, tar.gz/xz/zst/bz2, jar, …, also nested), Git branches, tags and commits (no checkout needed), and Git working trees.
- **Folder compare** with an aligned two-pane tree, filters, copy and delete, and a "≈ similar" status for files whose bytes differ but whose content is equal.
- **Text compare** with syntax highlighting (~190 languages including A2L, DBC, Intel HEX, S-record, ARXML), marks for changed words, whitespace and case rules.
- **Content views** for documents (Word, Excel, PowerPoint, OpenDocument, PDF; legacy Office through LibreOffice), executables (ELF, PE, Mach-O), firmware images (Intel HEX, S-record), images (pixel compare), minified XML/JSON and other binaries (hex dump).
- **Fast**: two Linux kernel releases (~87 000 files) compare in about 0.5 s on 4 cores.

Start the app with two paths to open a comparison directly, e.g.

```
ParallaxCompare.exe C:\src\shop@main C:\src\shop@feature\x
parallax ~/src/shop@main ~/src/shop@feature/x --merge-base
```

## Known limitations

This is an early preview. Not yet available: editing in the text view, 3-way merge, byte-aligned hex compare, saved sessions and settings, RAR archives, Git LFS. See the README for the roadmap.
