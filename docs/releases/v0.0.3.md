ParallaxCompare 0.0.3: find in the compare view, and a fix for the blank Linux AppImage window on newer distributions.

## Downloads

All files are standalone: no installer, nothing to set up.

| File | What it is |
|---|---|
| `ParallaxCompare-v0.0.3-windows-x64.exe` | Desktop app for Windows 10/11 (x64). Needs the Microsoft Edge WebView2 runtime, which Windows 11 and current Windows 10 already include. |
| `parallax-v0.0.3-windows-x64.exe` | Command-line tool for Windows |
| `ParallaxCompare-v0.0.3-linux-x86_64.AppImage` | Desktop app for Linux (x86-64). `chmod +x` and run. Without FUSE, run it with `--appimage-extract-and-run`. |
| `parallax-v0.0.3-linux-x86_64` | Command-line tool for Linux, statically linked |
| `SHA256SUMS.txt` | Checksums of all files |

The executables are not code-signed yet. Windows SmartScreen will warn on first start ("More info" → "Run anyway").

## New

- **Find in the compare view** (Ctrl+F): searches both sides, including rows not loaded yet. Matches are highlighted in the text and the overview strip and counted ("3 of 45"). Enter / F3 for the next match, Shift+Enter / Shift+F3 for the previous one. Options: match case, whole words, regular expressions. Selected text becomes the query, and matches follow unsaved edits.

## Fixed

- **Linux AppImage showed a blank window** on distributions with a newer Wayland than Ubuntu 22.04 (for example Arch and CachyOS), failing with "Could not create default EGL display: EGL_BAD_PARAMETER". The AppImage now uses the system's Wayland libraries (#1).

## Known limits

- Fonts and Android DEX files have no content view yet.
- Parquet/Arrow show the file summary, not the data rows.
- Find stops after 20,000 matches; the count then shows a "+".
