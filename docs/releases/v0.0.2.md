ParallaxCompare 0.0.2: text editing and merging, safer copy and delete, live updates, and content views for many more file formats.

## Downloads

All files are standalone: no installer, nothing to set up.

| File | What it is |
|---|---|
| `ParallaxCompare-v0.0.2-windows-x64.exe` | Desktop app for Windows 10/11 (x64). Needs the Microsoft Edge WebView2 runtime, which Windows 11 and current Windows 10 already include. |
| `parallax-v0.0.2-windows-x64.exe` | Command-line tool for Windows |
| `ParallaxCompare-v0.0.2-linux-x86_64.AppImage` | Desktop app for Linux (x86-64). `chmod +x` and run. Without FUSE, run it with `--appimage-extract-and-run`. |
| `parallax-v0.0.2-linux-x86_64` | Command-line tool for Linux, statically linked |
| `SHA256SUMS.txt` | Checksums of all files |

The executables are not code-signed yet. Windows SmartScreen will warn on first start ("More info" → "Run anyway").

## New

- **Edit and merge in the text view**: copy differences to the other side (arrows or Alt+←/→), edit lines, undo/redo, save (also into archives).
- **Safer copy and delete**: multi-select, a warning before replacing newer files, deleting to the Recycle Bin / Trash, progress and Cancel.
- **Live updates**: folders, archives and open files are watched; only the changed rows are compared again.
- **New content views**, each built to diff well (sorted, normalized, header-only reading for large files), most with a "≈ similar" rule:
  - AI models: GGUF (summary, chat template and rendered prompts, metadata, tokenizer, quantization), safetensors, ONNX graphs
  - Code: Java class files and jars, .NET assemblies (outline and IL), WebAssembly, Android binary XML
  - Data: SQLite (schema and rows), Parquet and Arrow, CSV/TSV sorted by key, YAML/TOML normalized, Jupyter notebooks, lockfiles (npm, yarn, pnpm, Cargo, Poetry, uv, pip, Composer, Bundler, Go)
  - Certificates and keys (PEM, DER, PKCS#12), e-mails (.eml, .msg)
  - Media: image metadata (EXIF, XMP, ICC, IPTC), audio and video containers (MP4/MOV, MKV/WebM, MP3, FLAC, Ogg, WAV, AIFF, AVI)
  - Automotive and embedded: DBC, A2L, linker map files, ELF debug symbols (DWARF), MDF4/MDF3 measurement files, CDFX calibration data

## Known limits

- Fonts and Android DEX files have no content view yet.
- Parquet/Arrow show the file summary, not the data rows.
