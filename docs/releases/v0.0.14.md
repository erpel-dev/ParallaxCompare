## Fixes from the desktop exploration (#17)

- Archive-member tabs reload current container contents after an external replacement. Saving an edited member checks the current contents and asks before overwriting an external edit, including replacements that preserve size and modification time. Nested archive indexes are invalidated together; unrelated external member edits remain preserved.
- Copying a filtered parent includes an archive when its matching member exists only on the destination, following the confirmation's whole-archive policy.
- Filtered parent copies prune unmatched directory trees before writing, for both folder and archive destinations. Explicitly selected and matching empty folders remain supported.
- Quoted or escaped filename patterns preserve leading and trailing spaces. Escaped commas inside glob alternatives keep their meaning, including when patterns are saved and restored.
- Correcting an invalid pattern clears its validation message even when the corrected pattern is already active, without clearing unrelated operation errors.
- Flat view continues pairing moved files when a same-name group exceeds the candidate limit, while keeping matching bounded.
- Closing a New comparison tab abandons its pending result and releases the late session. Finishing a comparison in the background preserves the currently selected tab.

## Other changes since 0.0.13

- Switch versions and sources on either side of an existing comparison, including Git revisions, file versions and archive paths. Git-ignored files can be included and marked.
- Startup defers command-line source inspection so the window stays responsive while slow sources open.
- Folder wildcards handle Unicode, glob alternatives, quoting and archive descendants more consistently (#13).
- Archive comparisons reuse metadata within each comparison, and Windows avoids copying an entire archive just to open it. Solid 7z decoding reads only as far as needed and can decode both sides concurrently (#14).
- The fixes from the earlier hour-long exploration (#12), including merge/text editing, save protection, archive rewriting, needs/YAML comparisons and long-path presentation, are included.

## Validation

Regression coverage includes literal filename patterns, matching across the flat-view threshold, filtered copies into folders and archives, and nested archive invalidation. The desktop checks exercise all eight findings from #17, including cancelling and accepting an external archive overwrite and reloading a clean archive-member tab.
