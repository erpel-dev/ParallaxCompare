ParallaxCompare 0.0.15 makes statuses, toolbars and long operations easier to follow, counts JSON with the same data as similar, and fixes a few issues found while testing.

## Downloads

| File | What it is |
|---|---|
| `ParallaxCompare-v0.0.15-windows-x64.exe` | Portable desktop app for Windows 10/11 (x64). Requires the Microsoft Edge WebView2 runtime. |
| `parallax-v0.0.15-windows-x64.exe` | Command-line tool for Windows |
| `ParallaxCompare-v0.0.15-linux-x86_64.AppImage` | Desktop app for Linux (x86-64). `chmod +x` and run; without FUSE, use `--appimage-extract-and-run`. |
| `parallax-v0.0.15-linux-x86_64` | Statically linked command-line tool for Linux |
| `SHA256SUMS.txt` | Checksums of the four executables |
| `LICENSE`, `THIRD-PARTY-NOTICES.md` | License and notices for included code |

This is a prerelease, following the project's convention for 0.x versions. The executables are not code-signed.

## Comparing

- JSON files with the same data in other formatting or key order are ≈ similar. They open pretty-printed with a note saying why and a link to the original text; the Text view names the view in which the files are equal.
- File views use the same status names as folders: Different, Left only, Right only, Same, Similar. A **?** button next to the filters explains each status and which rules decide ≈.
- A line under the folder tree names the status, reason and rule of the selected file.

## Toolbars and editing

- The folder toolbar has Previous / Next difference (F7/F8) instead of actions that were mostly disabled. Selected rows get a bar at the bottom to copy left↔right, delete on either side, or compare two rows with each other.
- Options say what they apply to and which status they affect; content options are disabled while comparing by size and date.
- Long paths drop their beginning and show the last part in bold.
- Undo and Redo are labelled, a Save button appears when there are unsaved changes, and merge conflicts have labelled Previous / Next buttons.
- Confirmations use an in-app dialog. **?** lists the keys of the current view.

## Long operations

- While a folder comparison runs, a progress line shows the files compared, the time taken and slow work such as *Decompressing release.7z*. Cancel keeps the results found so far and offers *Compare again*.
- `parallax --stats` prints the time taken and the peak memory.

## Fixes

- `.@v1.0:src` (a revision of the repository in the current folder) was taken for a remote `user@host:path` and failed with a `git fetch` error.
- Decoded files of solid 7z blocks are kept in memory up to 128 MB for all archives together, instead of 64 MB per block, so archives with many blocks no longer keep up to a gigabyte in memory.
- Typing `?` on a selected line opened the key list and also typed into the line.
