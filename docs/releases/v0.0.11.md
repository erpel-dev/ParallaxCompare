## Clickable count filters

- **Folder comparisons:** the toolbar count strip replaces All / Diffs / Same / Orphans. Click Different, Left only, Right only, Same, Similar or Errors to show that category; All differences includes changed files, one-sided files and errors. All files resets the status filter without clearing filename patterns.
- Matching parent folders remain visible and open when a category is selected. Totals stay fixed for the current comparison; the footer shows how many files match. Flat view counts moved file pairs once and updates as their comparisons finish.
- **File comparisons:** filter aligned rows by Changed, Added (right only), Removed (left only), Same or Ignored whitespace/case changes. Original line numbers are preserved. F7/F8 and the overview follow the filtered view.
- Filtering uses compact row ranges and keeps highlighted text loading lazy. A million-line desktop comparison opened in about 1.7 seconds and filtered to four distant changed rows in about 0.2 seconds in local validation.
- Editing, copying whole differences and selecting ranges restore all rows for full context. Find searches both whole files and restores all rows if a match was hidden. Unsaved edits remain in the buffer when changing filters.

## Context menus

- **Folder menus identify the clicked side and source.** Copy goes outward from that side, while open, reveal, path and delete actions apply to its entries. A missing-side placeholder offers copying the other file here. Multi-selection counts reflect entries actually present on the chosen side, and read-only actions explain why they are unavailable.
- **File menus identify the clicked line and side.** Copy selected text or lines, copy that difference outward, and edit, delete or save the chosen side where supported. Equal lines cannot act on a stale difference; the active line editor keeps its native text menu.
- Menus support keyboard navigation, Escape and focus restoration, with positioning that stays inside small windows.
