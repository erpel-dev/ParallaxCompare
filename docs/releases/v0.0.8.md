ParallaxCompare 0.0.8: older Office and Visio files are read without LibreOffice, folder results appear while comparing, and the second review's editing, copy and comparison fixes are included.

## Downloads

All files are standalone: no installer, nothing to set up.

| File | What it is |
|---|---|
| `ParallaxCompare-v0.0.8-windows-x64.exe` | Desktop app for Windows 10/11 (x64). Needs the Microsoft Edge WebView2 runtime, which Windows 11 and current Windows 10 already include. |
| `parallax-v0.0.8-windows-x64.exe` | Command-line tool for Windows |
| `ParallaxCompare-v0.0.8-linux-x86_64.AppImage` | Desktop app for Linux (x86-64). `chmod +x` and run. Without FUSE, run it with `--appimage-extract-and-run`. |
| `parallax-v0.0.8-linux-x86_64` | Command-line tool for Linux, statically linked |
| `SHA256SUMS.txt` | Checksums of all files |

The executables are not code-signed yet. Windows SmartScreen will warn on first start ("More info" → "Run anyway").

## New

- **Older Office files without LibreOffice**: Word 97–2003 `.doc` text, including tables, headers, footers, footnotes, endnotes, comments and text boxes; Excel 97–2003 `.xls` sheets with values and formulas; PowerPoint 97–2003 `.ppt` slide text and notes. They use the same Document text view as their newer Office counterparts.
- **Binary Visio files without LibreOffice**: `.vsd`, `.vss` and `.vst` files from Visio 2000–2010 are read directly for Diagram and Document text views. Drawings include shapes, text, geometry, data, masters and connections.
- **Folder results while comparing**: entries appear as soon as they are listed, with their comparison status filled in as work finishes. Archives inside compared folders are first compared as files; expanding one compares its entries. Expand and Flat open all archives. The CLI continues comparing archive contents immediately.

## Fixed

- **Editing**: keys and pastes typed while an earlier edit is being processed are kept and replayed in order. Pending line drafts count as unsaved, so closing, reloading or an external file change cannot silently discard them. Saving commits the draft first. Closing a tab during a slow load releases its late comparison result.
- **Copy and save**: folder copies respect file patterns and excludes, and copying a folder into itself or a descendant is refused before writing. Saving a symlink's target text keeps it a symlink. TAR hard links to earlier entries expose the referenced file's contents.
- **Remote Git**: option-shaped repositories and revisions are refused, Git arguments are separated from options, and remote-link parsing runs off the window thread. Git calls have deadlines. Gitea/Forgejo raw branch, tag and commit links select the correct revision.
- **Comparison accuracy**: all nbformat 3 notebook worksheets are included. Visio comparisons include master shapes, inherited text, geometry and other shape settings. A directory on either side stays expandable in a file/directory conflict. Existing local paths containing `!` open correctly.
- **Malformed models and images**: overflowing GGUF tensor dimensions produce an error, and a converter failure on either side falls back with a note. Blink preserves each image's dimensions and aspect ratio.

These changes address the findings in [the second review, #9](https://github.com/erpel-dev/ParallaxCompare/issues/9).

## Known limits

- Word 6/95, Visio 5 and older files, and files the native readers cannot handle still need LibreOffice for conversion. Excel formulas shared across a range show their cached values.
- Fonts and Android DEX files have no content view yet.
- Parquet/Arrow show the file summary, not the data rows.
- Find stops after 20,000 matches; the count then shows a "+".
- Open/reveal actions in the path-bar menu remain disabled for local names containing `!`; comparing those paths works.
