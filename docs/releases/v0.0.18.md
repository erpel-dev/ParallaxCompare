ParallaxCompare 0.0.18 lets you review a pull request from the comparison: comment on lines, reply, resolve, and submit your review.

## Downloads

| File | What it is |
|---|---|
| `ParallaxCompare-v0.0.18-windows-x64.exe` | Portable desktop app for Windows 10/11 (x64). Requires the Microsoft Edge WebView2 runtime. |

## Reviewing pull requests

Everything is written with the `gh` sign-in the comparison already uses, as the signed-in user, and only by an explicit button.

- **Comments on lines:** select lines of the merge base or head and press **C**. The comment box in the panel has Write / Preview and, on the head, *Suggest change*. Lines GitHub's diff accepts are marked beside the line numbers; *Comment on the file* comments on a file as a whole. Comments on lines need the compared head to be the PR's current one.
- **Your review is GitHub's pending review:** *Start a review* (Ctrl+Enter) and *Add to review* add to it; its comments show as Pending and can be edited or deleted until you submit. A review started in the browser shows up in the app and the other way round.
- **Finish review** (Ctrl+Shift+Enter): a summary and Comment, Approve or Request changes (not on your own PR), with the list of what is sent; *Discard review* deletes it. *Comment now* posts a single comment while no review is pending.
- **Threads:** reply (**R** at the selected line), *Reply and resolve*, *Resolve* / *Unresolve*; *Edit* and *Delete* on your own comments, deleting after a confirmation.
- Buttons appear only where GitHub allows them; text being written is kept on this computer until it is sent.

## Also

- The counts on files and folders open the panel for them; CI findings open their file at their line.
- *On GitHub* and *Comment on GitHub* still open the PR's Files changed page at the selected lines.
