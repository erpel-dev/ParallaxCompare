ParallaxCompare 0.0.5: a file pattern filter in the folder compare, folders as new base folders from the row menu, and tabs that can be dragged into another order.

## Downloads

All files are standalone: no installer, nothing to set up.

| File | What it is |
|---|---|
| `ParallaxCompare-v0.0.5-windows-x64.exe` | Desktop app for Windows 10/11 (x64). Needs the Microsoft Edge WebView2 runtime, which Windows 11 and current Windows 10 already include. |
| `parallax-v0.0.5-windows-x64.exe` | Command-line tool for Windows |
| `ParallaxCompare-v0.0.5-linux-x86_64.AppImage` | Desktop app for Linux (x86-64). `chmod +x` and run. Without FUSE, run it with `--appimage-extract-and-run`. |
| `parallax-v0.0.5-linux-x86_64` | Command-line tool for Linux, statically linked |
| `SHA256SUMS.txt` | Checksums of all files |

The executables are not code-signed yet. Windows SmartScreen will warn on first start ("More info" → "Run anyway").

## New

- **File patterns in the folder compare**: a field in the toolbar takes patterns such as `*.java *hello*w*c` (separated by spaces, commas or semicolons). Only matching files are compared and shown, and folders without any are left out, so a filtered compare of a large tree is also faster. A pattern matches the file name, ignoring case, or the path when it contains `/` (`src/**/*.rs`); a matching folder or archive keeps everything in it. Enter applies at once, Esc clears. The CLI takes the same patterns with `--include`.
- **Set as base folder**: right-click a folder or archive in a folder compare to make it the top folder of the left side, the right side, or both. Back returns to the previous comparison.
- **Reorder tabs** by dragging them; the tab bar scrolls along near its edges. Ctrl+Shift+PageUp/PageDown moves the current tab. Open comparisons keep their scroll position and selection.

## Known limits

- Fonts and Android DEX files have no content view yet.
- Parquet/Arrow show the file summary, not the data rows.
- Find stops after 20,000 matches; the count then shows a "+".
