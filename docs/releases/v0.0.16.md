ParallaxCompare 0.0.16 makes file diffs easier to read, shows more in folder comparisons, matches ECUC values by short name, and warns before an edit is saved into a malformed file.

## File comparison

- A filtered view keeps 3 lines of context around each difference (none, 3 or 10, next to the filters), and each unchanged stretch folds into one bar that opens in place, 20 lines at a time or all.
- Right-only lines are blue, like the Right only status everywhere else. A changed phrase is one mark instead of one per word, and lines with little in common are not marked word by word.
- The copy arrows of the current row are labelled buttons; *Wrap line* shows the whole selected line, wrapped, under the rows.
- Edits that make an XML (ARXML, XSD, SVG, ODX, CDFX …), JSON, YAML or TOML file malformed are named in a warning with the line, and saving asks first. Files that were not well-formed to begin with are not warned about.

## ECUC values

- Containers, parameters and references on the same level are matched by name (short name, definition, or the value for list entries), not by their text: a renamed container is one removed and one added block, a changed value one changed line.
- Copying between the sides was tested on 14 kinds of differences in both directions, with 316 saves, each checked to be well-formed, a valid ECUC structure and exactly the edited configuration.
- The view cannot save text that no longer reads; it says what is wrong and where.

## Folder comparison

- Collapsed folders list what they hold by status (`5 ≠ 1 ▶`); a bar under the filters shows the share of each status and filters on click; a *Change* column gives the size difference, and the newer date is bold.
- Entries that could not be read or compared are named in one banner, grouped by cause, with *Show them*, *Retry* and *Copy the list*.
- The progress line counts the files compared of those found, with the time left once the count has settled.
- Below about 1000 px the toolbar uses short buttons and one filter menu.

## App

- Preferences (the gear in the tab bar, or Ctrl+,): theme, text size (also Ctrl++ / Ctrl+− / Ctrl+0), the default context lines, and the app's version and build details to copy.

## Fixes

- `folder@rev` for a folder inside a work tree compared the repository's root at that revision; it now keeps the folder.
- Solid 7z comparisons recover when temporary storage fills up, report the archive and temporary folder, and offer to retry; reads of large entries are bounded (#19).
- Copies stay inside the chosen destination folder, also through links; output of helper programs is bounded; failures at the comparison's root show consistently (#21).
- Bulk selection, search in long lines, history shortcuts and comparison diagnostics (#22).
