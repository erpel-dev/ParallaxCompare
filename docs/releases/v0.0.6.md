ParallaxCompare 0.0.6: files and folders of remote Git repositories can be compared straight from a link, and text is edited by clicking into it, like in an editor.

## Downloads

All files are standalone: no installer, nothing to set up.

| File | What it is |
|---|---|
| `ParallaxCompare-v0.0.6-windows-x64.exe` | Desktop app for Windows 10/11 (x64). Needs the Microsoft Edge WebView2 runtime, which Windows 11 and current Windows 10 already include. |
| `parallax-v0.0.6-windows-x64.exe` | Command-line tool for Windows |
| `ParallaxCompare-v0.0.6-linux-x86_64.AppImage` | Desktop app for Linux (x86-64). `chmod +x` and run. Without FUSE, run it with `--appimage-extract-and-run`. |
| `parallax-v0.0.6-linux-x86_64` | Command-line tool for Linux, statically linked |
| `SHA256SUMS.txt` | Checksums of all files |

The executables are not code-signed yet. Windows SmartScreen will warn on first start ("More info" → "Run anyway").

## New

- **Remote Git repositories**: paste a link to a file or folder on GitHub, GitLab, Bitbucket or Gitea/Codeberg (`https://github.com/o/r/blob/main/src/lib.rs`, `…/tree/v1.4/src`, `raw.githubusercontent.com/…`), or a clone URL with a revision (`https://host/o/r.git@v1.4:src`, `git@host:o/r.git@main`), wherever a path goes: the new-comparison form, the path bars and the CLI. Only the commit compared is fetched, with the installed `git`, so private repositories work with the credentials Git already has. Branch names with `/` in links are looked up on the remote, and the Git ref picker lists the remote's branches and tags. Needs Git installed.
- **Editing like in an editor**: a single click in a line puts the caret there, no double-click first. ← at the start of a line goes to the end of the line above, → at the end to the next line. Typing on a selected line edits it, and Space types a space instead of scrolling. Escape keeps what was typed. Whole lines are selected by clicking the line number, Shift+click or Shift+↑/↓.

## Changed

- The `n` and `p` shortcuts for the next and previous difference work on read-only sides only, since on editable sides letters type; F7 and F8 work everywhere.
- The CLI names the Git revision in the headers of a file diff (`--- repo › file @ v1.4`).

## Known limits

- Fonts and Android DEX files have no content view yet.
- Parquet/Arrow show the file summary, not the data rows.
- Find stops after 20,000 matches; the count then shows a "+".
