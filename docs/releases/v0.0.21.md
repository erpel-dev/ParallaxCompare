ParallaxCompare 0.0.21 improves navigation and refresh in Folder Compare and adds an experimental desktop front end for source builds.

- **Folder Compare navigation.** Previous and Next difference follow the active filter and the displayed order in Flat view. Opening a Flat result uses the file's actual path, including for matched files in different folders. ([#43](https://github.com/erpel-dev/ParallaxCompare/pull/43))
- **Folder Compare refresh.** Refresh keeps expanded folders, selection, and scroll position. If you cancel a refresh, the retained comparison is labeled as a previous result. Changes to files whose names contain line breaks now invalidate the cached comparison. ([#43](https://github.com/erpel-dev/ParallaxCompare/pull/43))
- **GPUI prototype.** The experimental front end shares the comparison and merge core with the Tauri app. It supports folder and text comparisons, watches for local file changes, and offers three-way merge and Git mergetool mode. The downloadable desktop builds use Tauri and Svelte. Build the prototype from source using the [GPUI instructions](https://github.com/erpel-dev/ParallaxCompare/blob/v0.0.21/app-gpui/README.md). ([#44](https://github.com/erpel-dev/ParallaxCompare/pull/44))
