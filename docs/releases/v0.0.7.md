ParallaxCompare 0.0.7: Microsoft Visio drawings are compared by their shapes, text, data and connections.

## Downloads

All files are standalone: no installer, nothing to set up.

| File | What it is |
|---|---|
| `ParallaxCompare-v0.0.7-windows-x64.exe` | Desktop app for Windows 10/11 (x64). Needs the Microsoft Edge WebView2 runtime, which Windows 11 and current Windows 10 already include. |
| `parallax-v0.0.7-windows-x64.exe` | Command-line tool for Windows |
| `ParallaxCompare-v0.0.7-linux-x86_64.AppImage` | Desktop app for Linux (x86-64). `chmod +x` and run. Without FUSE, run it with `--appimage-extract-and-run`. |
| `parallax-v0.0.7-linux-x86_64` | Command-line tool for Linux, statically linked |
| `SHA256SUMS.txt` | Checksums of all files |

The executables are not code-signed yet. Windows SmartScreen will warn on first start ("More info" → "Run anyway").

## New

- **Visio drawings** (`.vsdx`, `.vsdm`, `.vstx`, `.vssx` and the older `.vsd`, `.vss`, `.vst`): a new Diagram view lists every page with its size and every shape with its text, position and size, shape data (`data: label = value`), master, and for connectors the shapes they join (`shape 2 "Shape B" → shape 5 "Shape C"`). Grouped shapes are indented under their group. The Document text view shows only the text. Drawings with the same content are marked ≈ in folder compares, even when the file was saved again. `.vsd`, `.vss` and `.vst` files need LibreOffice installed and take about 1.5 s per file to convert.

## Known limits

- Fonts and Android DEX files have no content view yet.
- Parquet/Arrow show the file summary, not the data rows.
- Find stops after 20,000 matches; the count then shows a "+".
