## Pull request conversations

A pull request comparison reads the PR's conversation in the background, read-only, with the `gh` sign-in it already uses (github.com and GitHub Enterprise).

- **Bar above the comparison:** who approved or requested changes, review bots, checks, open threads, *Open on GitHub*, and read again.
- **Folder view:** open threads (💬), findings (●) and CI warnings (▲) on each file and folder; *Only files with comments*; a panel with every thread (open, resolved, outdated) and the PR's reviews and comments. Clicking a thread opens its file at that line.
- **File view:** markers beside the line numbers and in the overview strip, a panel with the file's threads that follows the selected line, and F9 / Shift+F9 between threads.
- **Findings:** threads a review bot marks as Important (🔴 and similar) and failed CI annotations. Suggested changes show as added lines to copy.
- **Placement:** threads are placed on lines only while the compared head is the PR's current head; outdated threads, comments on a whole file and threads after a newer push are listed without a line, with *Open the new head*.
- **Safety:** comment text is shown without raw HTML, images are not loaded, and only links to the PR's own GitHub host open (others are copied).
- **Without a signed-in gh** the comparison works as before; the bar says how to sign in.

Replying to and resolving threads are not included.
