What changes from today

The two-pane context menu becomes a menu for the clicked pane. There is one copy direction, one delete action and one set of Open / Reveal / Copy path actions. Open comparison stays available from either pane.

When the context changes

A Git revision can still be copied out, but cannot be overwritten or deleted. A missing file offers Copy right file here. Multi-selection shows how many files on that side will be affected.
