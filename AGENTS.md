# Project instructions

## Authorship and attribution

- Never add yourself, an AI assistant, model, or AI vendor as an author, co-author, committer, or contributor.
- Use the user's configured Git identity for new commits. Never override it with an AI identity through Git configuration, environment variables, or `--author`.
- Do not add AI `Co-authored-by`, `Signed-off-by`, session links, "Generated by", "Assisted by", or similar attribution trailers, signatures, or footers to commits, pull requests, issue and pull request comments, reviews, source files, documentation, release notes, or contributor lists.
- Before committing or opening a pull request, check the identity and text for unwanted AI attribution and remove any you introduced.
- Preserve legitimate human attribution and third-party license notices. Do not rewrite existing Git history unless the user explicitly requests it.
